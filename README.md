# サークルづくり

**BESTIA WORKS Apps / 同人イベントの準備と当日を支えるアプリ**

荷造り、やること、当日の予定、レジ・在庫をイベントごとに管理できます。BESTIA WORKSが制作するアプリのひとつです。

[BESTIA WORKS](https://bestiaworks.com/) · [アプリ紹介](https://bestiaworks.com/app-list/circle-prep/) · [ダウンロード](https://github.com/riotaro015/circle-prep/releases/latest)

## ダウンロード

[Releases](https://github.com/riotaro015/circle-prep/releases) で Android版APKとSHA-256チェックサムを配布しています。各版の変更内容もこちらに掲載します。

このリポジトリはアプリの紹介・配布・利用案内用です。開発用ソースコードは含みません。

## できること

- イベントの新規作成と切り替え
- 遠征・近場・空の状態から選ぶ荷物のひな形
- バッグ別の持ち物・荷造りチェック
- やることリストとタイムライン
- 商品・在庫・現金会計・売上記録の管理
- 会場マップ、サークルのハイライト、自分のスペース、おしながき・買い物メモ
- イベント別のカード式メモと保存データ量の目安
- 記録のファイル書き出しと復元

## Android版の導入

Android 8.0以上が対象です。現在の配布版はテスト版です。

1. Releasesから `.apk` ファイルをダウンロードします。
2. ファイルを開き、Androidの案内に従ってインストールします。必要に応じて、ダウンロードに使ったブラウザなどの「この提供元のアプリを許可」を設定します。
3. 「サークルづくり」を起動し、イベントを作成するか、同梱のイベントデータを選びます。

更新するときは、先に設定からバックアップを書き出し、新しいAPKを上書きインストールしてください。既存アプリをアンインストールすると端末内の記録が消えます。

**公開テスト版：0.1.3-preview.5**。旧0.1.2からの上書き更新とイベント保持、メモの再起動後の保持をAndroidエミュレーターで確認しています。実機での動作確認は継続中です。

旧版ではAPKを保存したあと、設定の「APKを選んで更新」から選べます。新版では設定の「GitHub Releases」から配布ページを外部ブラウザーで開けます。最新版の自動ダウンロード・自動インストールは行いません。

## マップとイベントデータ

野郎フェス2026-autumn-の公開サークル一覧を収録しています。会場図は利用者が画像を登録して位置を指定します。操作確認用マップは、実際の会場配置とは異なることを画面に明示しています。

配布イベントは取得日を基準に、開催予定・開催日未定・過去開催へ分けて表示します。過去開催は折り畳んで選択できます。入場時刻や搬入条件は、主催者の最新案内をご確認ください。

## 記録と通信

Android版は画面・フォント・イベントデータを同梱した完全ローカル版です。インターネット権限はなく、記録をサーバーへ送信しません。ログインやクラウド同期はありません。

APKの配布ページは外部ブラウザーで開きます。メモ・マップ画像・おしながきも端末内で保存し、全体バックアップに含めます。イベントに表示する容量は、保存データの目安であり、アプリ全体のディスク使用量ではありません。

記録は端末内に保存されます。機種変更やアプリ削除の前にバックアップを書き出し、端末外にも保管してください。同梱イベント情報は収録時点のものです。参加時は主催者の最新案内を確認してください。
